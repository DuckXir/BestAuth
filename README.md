# 🛡️ BestAuth

Modern, lightweight, and ultra-secure authentication plugin for Minecraft 1.21+ (Paper, Purpur, Spigot).

## ✨ Features
- 🔒 **SHA-256 + Salt** cryptographic password encryption
- 🌐 **Anti-Bot / Multi-Account Limit** per IP address
- ⚡ **Asynchronous SQL** (YAML, SQLite, MySQL)
- 🌍 **4 Languages:** English (en), Turkish (tr), German (de), Spanish (es)
- 💰 **Vault Economy** registration reward support

## 🚀 Build from Source
```bash
mvn clean package
```
Output JAR will be in `target/BestAuth-1.0.0.jar`.
